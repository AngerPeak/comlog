COMLOG для iPhone (веб-приложение)
=====================================

Эта папка — готовое приложение для телефона. Его нужно один раз выложить
на бесплатный хостинг GitHub Pages, а потом установить на iPhone.
Ваших заказов здесь НЕТ: данные хранятся только на устройствах
и (если включите) в зашифрованном виде в вашем приватном Gist.


1. ВЫЛОЖИТЬ НА GITHUB PAGES (один раз, ~10 минут, с компьютера)
------------------------------------------------------------------
1) Зарегистрируйтесь на https://github.com (бесплатно).
2) Нажмите «+» вверху справа → New repository.
   Repository name: comlog   ·   Public   ·   Create repository.
3) На странице репозитория нажмите «uploading an existing file».
4) Перетащите в окно ВСЁ СОДЕРЖИМОЕ этой папки (index.html, css, js,
   fonts, icons, manifest.webmanifest, sw.js) → Commit changes.
5) Settings → Pages → Branch: main, папка / (root) → Save.
6) Через 1–2 минуты появится адрес вида:
      https://ВАШ-ЛОГИН.github.io/comlog/
   Его можно открыть и на компьютере — это та же программа.

Обновление: после новой сборки снова загрузите файлы (Add file → Upload files)
с заменой. Телефон подхватит новую версию при следующем открытии.


2. УСТАНОВИТЬ НА iPhone
------------------------
1) Откройте адрес из шага 1.6 именно в Safari.
2) Кнопка «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → Добавить.
3) Запускайте COMLOG с иконки на экране — он откроется без адресной строки
   и будет работать даже без интернета.

Важно: данные иконки на экране «Домой» и вкладки Safari — разные хранилища.
Пользуйтесь приложением с иконки.


3. СИНХРОНИЗАЦИЯ С ПК
----------------------
На ПК (COMLOG.exe) → Настройки → «Синхронизация ПК ↔ iPhone»:
1) Нажмите «Получить токен на GitHub →». Откроется страница создания токена,
   где уже отмечено право «gist». Expiration — No expiration → Generate token.
   Скопируйте токен (начинается с ghp_).
2) Вставьте токен в COMLOG → «Создать». Нажмите «Копировать» у кода подключения
   и отправьте его себе (например, в «Избранное» Telegram).
3) На iPhone: COMLOG → Ещё → Настройки → «Синхронизация» → вставьте код
   в поле «На втором устройстве» → «Подключить».

Дальше всё синхронизируется само: при запуске, после изменений и раз в 3 минуты.
Правки с двух устройств аккуратно объединяются по каждому заказу.
Код подключения никому не показывайте — в нём ключ к вашим данным.

Без синхронизации можно переносить данные вручную:
ПК → Настройки → «Сохранить бэкап в файл» → отправить файл на телефон →
iPhone → Настройки → «Восстановить из бэкапа».


4. НАПОМИНАНИЯ НА iPhone
-------------------------
Веб-приложения на iPhone не умеют сами присылать уведомления без своего сервера.
Поэтому: Настройки → «Дедлайны в Календарь (.ics)» → открыть файл →
«Добавить все». Календарь iOS напомнит накануне дедлайна в выбранные часы.
(Календарь iPhone показывает не больше двух напоминаний на событие.)
В самом приложении сроки подсвечиваются колокольчиком и подсказками.


5. ДРУЗЬЯМ
-----------
Можно просто дать ссылку из шага 1.6 — у каждого будет своя пустая база.


6. ОБНОВЛЕНИЯ НА ПК — ТОЖЕ САМИ
--------------------------------
COMLOG.exe при запуске проверяет ваш сайт на GitHub Pages и, если там версия
новее встроенной, открывает интерфейс прямо с сайта. Без интернета — работает
встроенная версия. Данные всегда хранятся на компьютере.

Адрес сайта ПК узнаёт сам через синхронизацию с телефоном. Без синхронизации
впишите его вручную: Настройки → «Обновления» → «Адрес веб-версии».
Отключить: там же, «Обновляться с сайта».

Итого после правок достаточно загрузить папку COMLOG PWA на GitHub —
обновятся и телефоны, и ПК, и друзья (если они пользуются вашей ссылкой).
Новый COMLOG.exe нужен, только если меняется сама оболочка программы.
